# 修复思考过程、聊天滚动与工具折叠

## Goal

恢复推理模型的“思考过程”展示，并让流式消息、底部任务进度条和输入区高度变化时的聊天滚动稳定、连续、可控；同时降低工具调用消息的视觉占用，使历史对话更容易浏览。

## Background

- `src/shared/api/sse.ts:14-24` 在最近重构中为 SSE 增量增加了 Zod 校验，但 `content` 与 `reasoning_content` 只接受字符串。OpenAI-compatible 推理模型可能在推理片段中发送 `content: null`，导致整条增量校验失败，思考内容被静默丢弃。
- `src/features/agent-core/engine.ts:463-470` 在纯文本完成分支重新构造 assistant 消息时只保留 `content`，会丢失本轮已经收集到的 `reasoning_content`。
- `src/features/chat/hooks/useChatAutoScroll.ts:7-20` 在每次流式更新和 composer 高度变化时启动新的 smooth scroll。连续增量会反复重启动画，并在程序滚动产生的中间位置触发 `isAtBottom` 变化，形成抖动或“鬼畜滚动”。
- `src/features/chat/ui/Chat.css:13-15` 当前思考区域的内边距为 16px、内容最大高度为 120px，视觉占用偏大。
- `src/features/chat/ui/ChatMessage.tsx:26-34` 当前工具参数与结果始终展开，且完成后标题仍显示“执行中”。

## Requirements

### R1. 恢复并保留思考过程

- SSE 边界必须接受 provider 合法返回的 `null` content/reasoning 字段，并将其规范化为空增量，而不是丢弃整个事件。
- 字符串形式的 `reasoning_content` 必须继续增量合并、实时投影，并在最终 assistant 消息中保留。
- 无工具调用的纯文本最终回复也必须保留 `reasoning_content`。
- 仍然拒绝字段类型明显错误的 provider 数据，不放宽为未验证的任意对象。

### R2. 缩小思考过程栏目

- 思考卡片降低内边距、底部间距和内容最大高度。
- 内容超过约 72px 时在卡片内部滚动；流式输出继续自动跟随该内部滚动区域。
- 保持现有标题、流式光标和三语言文案。

### R3. 稳定聊天自动滚动

- 用户停留在底部时，流式内容、消息完成、输入区/任务条保留高度变化后继续贴底。
- 自动跟随使用同步/无动画的底部校正，不在每个 token 增量上反复启动 smooth scroll。
- 只有用户主动点击“回到底部”时使用平滑滚动。
- 用户手动向上浏览历史后，后续流式更新不得抢夺其滚动位置。
- composer 底部保留空间的变化不得再通过 CSS 高度过渡制造未被重新锚定的中间 scrollHeight。
- 现有向上加载历史消息时的视口补偿和 250-message 窗口行为保持不变。

### R4. 工具调用默认折叠

- 除 `ask_user` 外，每个工具调用使用语义化、键盘可操作的折叠控件。
- 工具卡片默认关闭；摘要行始终显示工具名和运行/完成状态。
- 内部工具折叠行不使用描边，依靠浅色背景、间距和圆角区分层级；外层消息卡片边界保持不变。
- 展开后的参数与结果代码块使用白色 surface 背景，与浅灰工具容器形成清晰层级。
- 展开后显示原有参数与结果，长结果继续在内部滚动。
- 展开/折叠时，工具气泡的固有宽高使用非线性缓动连续过渡；若操作发生在聊天底部，动画期间继续稳定贴底，用户滚轮或触摸滚动可立即中止跟随。
- 尊重系统的“减少动态效果”设置，关闭尺寸与内容动效但保留完整交互。
- 已有结果的工具显示“已完成”，未产生结果时显示“执行中”；中英日文案同步。

### R5. 全局动效一致性

- 全局空间、尺寸、面板和箭头变化使用共享的非线性 motion token；颜色和透明度反馈保持短促，不滥用弹簧。
- CSS 退场时长必须与 React presence 保留时间一致，移动底部菜单不得被提前卸载；模型选择器必须有真实退场动画。
- 不使用会触发布局重排的 `font-size` 选中态动画；终端标签改用稳定字号、字重和轻微 transform。
- 工具消息外层与灰色 disclosure 的左右 padding 分别缩窄为与上下相同的 16px 和 8px。

## Acceptance Criteria

- [x] 含 `content: null` 与字符串 `reasoning_content` 的 SSE 事件会显示并保留思考过程。
- [x] 纯文本最终回复的持久消息包含模型返回或流式收集到的 `reasoning_content`。
- [x] 思考内容区域最大高度约为 72px，溢出内容可内部滚动。
- [x] 连续流式更新不会重复调用 smooth scroll；位于底部时视口稳定贴底。
- [x] 用户向上滚动后，流式更新不改变其阅读位置；点击“回到底部”仍平滑返回。
- [x] composer/任务摘要高度变化后，聊天底部不被遮挡且不出现来回抖动。
- [x] 工具调用初始为折叠状态，点击摘要可查看参数和结果，并能区分运行中与已完成。
- [x] 工具气泡展开/折叠时宽高、内容和箭头使用非线性动画连续过渡，底部视口不抖动，减少动态效果偏好生效。
- [x] 全局动效角色、退场 presence 时长和终端选中态经过审计；移动菜单不截断、模型菜单不延迟消失，工具气泡四边间距一致。
- [x] `ask_user` 继续直接展示，历史分页、消息窗口和工具结果索引行为无回归。
- [x] 新增单元/组件测试覆盖 nullable SSE、最终 reasoning 保留、滚动策略和工具折叠交互。
- [x] `npm run check` 与适用的全量 UI/Agent 检查通过。

## Out of Scope

- 展示 provider 不返回的隐藏思维链或自行生成伪造 reasoning。
- 改变 RunBoard 的任务状态机、持久化 schema 或 250 条消息分页策略。
- 为工具卡片增加用户级“记住展开偏好”设置。
- 重做聊天视觉设计或引入虚拟列表。

## Technical Notes

- Provider 兼容性修复归属 `shared/api` 边界；AgentEngine 只负责保留规范化后的消息字段。
- 滚动跟随状态属于 `useChatAutoScroll` 的瞬态 UI 状态，不进入 workspace store 或持久化。
- 折叠状态为每个渲染实例的本地浏览器状态，使用原生 `details/summary` 即可满足默认关闭和键盘访问。
