# 统一操作菜单与工作区文件工具

## Goal

修复文件管理器和历史对话栏的可见回归，并将应用内资源操作菜单统一为一套可复用、响应式的交互，使桌面端使用锚定浮层、移动端使用底部选项抽屉，同时补齐完整工作区 ZIP 导出能力。

## Background

- 文件列表首次加载时只显示缓存过的大小，未被预览或读取的文件显示“未知”。
- 历史对话重命名时仍显示状态、展开箭头和更多按钮，输入框会与尾部控件重叠。
- 历史对话的状态圆点、展开箭头和更多按钮分别绝对定位，难以保持稳定间距。
- 会话/容器、文件条目和子 Agent 操作菜单分别实现了 portal、presence 和菜单结构；子 Agent 菜单还有一套移动端例外样式。
- 文件工具栏将新建文件、新建文件夹和上传文件分别显示为三个图标，移动端占用空间较多。
- WebContainer 原生支持将指定目录导出为 ZIP 字节流，完整工作区导出不需要增加压缩依赖。

## Requirements

### R1 文件大小

- 文件列表首次打开或刷新后必须显示每个可读普通文件的真实字节大小，不要求用户先预览文件。
- 大小读取必须限制并发，避免一次性无界读取大量目录项。
- 单个文件读取失败不得阻断整个目录列表；该文件可以继续显示本地化的“未知”。
- 目录排序、根目录边界和过期导航结果保护保持不变。

### R2 历史对话行布局

- 历史对话进入重命名状态时，只保留前导会话图标和可用宽度内的输入框；状态、展开箭头和更多按钮全部隐藏。
- 非重命名状态下，生命周期状态与展开箭头进入同一个稳定的尾部控件组。
- 无子 Agent 的会话不显示展开箭头；有子 Agent 的会话保留现有展开、选择与返回根对话语义。
- 状态优先级、未读颜色、运行/生成动画和更多菜单行为保持不变。
- 桌面与移动宽度下均不得出现输入框、状态、箭头或更多按钮重叠。

### R3 共享响应式操作菜单

- 提供一个位于 shared UI 层的公共操作菜单组件，统一动作项、分隔线、危险操作、遮罩、body portal、进入/退出 presence 和定位入口。
- 桌面端统一显示在触发位置附近的锚定浮层，并限制在 viewport 内。
- 移动端统一显示带遮罩的底部选项抽屉，包含安全区内边距和统一进退场动画。
- 会话/容器菜单、文件条目菜单、子 Agent 删除菜单和新增文件工具菜单全部迁移到公共组件。
- 子 Agent 删除菜单不再保留移动端锚定浮层例外；其删除语义与失败时保留记录的行为不变。
- 右键与显式更多按钮继续打开同一套菜单；点击遮罩和完成动作后关闭菜单。
- 设置模态框、确认对话框、任务列表展开层等非资源操作菜单不纳入本次标准化。

### R4 文件工具菜单

- 文件工具栏保留独立刷新按钮。
- 新建文件、新建文件夹和上传文件三个按钮合并为一个“更多操作”图标入口。
- 菜单提供新建文件、新建文件夹、上传文件和导出完整工作区四项操作，并使用清晰的 Lucide 图标和本地化文本。
- 新建与上传行为继续作用于当前目录；导出行为始终作用于当前容器根目录。

### R5 完整工作区导出

- “导出完整工作区”将当前容器根目录完整打包为一个 ZIP 并触发浏览器下载，不受当前浏览目录影响。
- 完整导出不应用持久化快照的排除规则；隐藏文件、`node_modules`、构建输出及其他容器内容均包含在 ZIP 中。
- 导出进行中必须防止重复触发，并提供明确的进行中状态。
- 导出失败必须显示在文件管理器现有可见错误区域，不得静默失败。
- 下载对象 URL 必须在触发下载后释放。

## Acceptance Criteria

- [x] AC1 新打开包含文本和二进制文件的目录时，无需预览即可看到正确格式化的文件大小；单文件读取失败仅使该文件显示“未知”。
- [x] AC2 快速切换容器根或目录时，过期的目录/大小读取结果不会覆盖当前列表。
- [x] AC3 会话重命名时状态、展开箭头和更多按钮不在 DOM 中或不可见，输入框占满尾部之前的可用空间且无重叠。
- [x] AC4 普通状态下状态和展开箭头位于同一尾部组；有/无子 Agent、运行、成功未读、失败未读等组合布局稳定。
- [x] AC5 四类操作菜单均通过同一共享组件渲染并 portal 到 `document.body`；桌面为 viewport 内锚定浮层，移动为底部选项抽屉。
- [x] AC6 子 Agent 菜单在移动端与其他操作菜单一致为底部抽屉，仍只包含删除且删除失败时保留记录和当前视图。
- [x] AC7 文件工具栏只显示刷新和一个更多操作入口；菜单可执行新建文件、新建文件夹、上传文件和完整工作区导出。
- [x] AC8 从任意子目录触发导出时，下载的 ZIP 来自容器根且包含嵌套目录、隐藏文件和依赖目录；导出失败可见，重复触发被阻止。
- [x] AC9 中文、英文、日文文案完整，桌面和移动视觉检查无溢出、遮挡或不一致菜单形态。
- [x] AC10 相关单元/组件/E2E/视觉/真实 WebContainer 测试、`npm run check:all` 和 `git diff --check` 通过。

## Out Of Scope

- 更改删除确认、权限、持久化或 Agent 取消语义。
- 为 ZIP 导出增加快照式排除项、文件选择器或导入 ZIP 功能。
- 标准化非操作菜单类的 modal、确认框、任务展开层或服务预览层。
- 重设计文件列表、侧栏宽度或导航结构。
