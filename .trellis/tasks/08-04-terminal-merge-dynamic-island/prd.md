# 移动终端滚动修复 + 表格横向滚动 + 电脑/终端/服务合并灵动岛

## Goal

- 移动端（≤900px 及触屏设备）「Sunam的电脑」与「终端」的 xterm 视图可触摸拖拽滚动（含滚动条可用）。
- 聊天气泡内 Markdown 表格改为内部横向滚动，避免列被挤压。
- 将「Sunam的电脑 / 终端 / 服务」三个容器视图合并为单一「Sunam的电脑」视图，加入与任务列表同风格的胶囊型灵动岛分段滑块（点击 / 移动端滑动切换）；排序不变；文件、能力库保持独立顶级标签。

## Requirements

### R1 移动端终端触摸滚动

- R1.1 在「Sunam的电脑」（只读 AI 终端）与「终端」（用户 shell）视图中，单指纵向拖拽可滚动终端回滚缓冲；桌面鼠标滚轮行为不回归。
- R1.2 xterm 自定义滚动条在触屏上可拖拽（指针事件生效）。
- R1.3 横向主导的拖拽不拦截，交由灵动岛滑动切换消费；不影响终端点击聚焦。
- R1.4 触摸监听在终端卸载时完整清理。

### R2 聊天气泡表格横向滚动

- R2.1 表格宽度按其内容自适应（不再 `width:100%` 被挤压），窄容器内通过内部横向滚动查看全部列。
- R2.2 表格仍保持当前圆角/边框/斑纹（`.markdown-table-wrap`）视觉；滚动容器不破坏聊天气泡布局。

### R3 合并视图与胶囊灵动岛

- R3.1 顶级容器标签收敛为：**Sunam的电脑 / 文件 / 能力库**（桌面 `TerminalTabs`、折叠栏、移动底部导航三处同步）；终端、服务不再作为顶级标签。
- R3.2 在「Sunam的电脑」视图内，胶囊灵动岛切换 电脑(`ai`) / 终端(`user`) / 服务(`services`) 三个子视图；顺序不变。
- R3.3 灵动岛与任务列表胶囊同风格（`glass-input` 玻璃材质、圆角、动效 token）；内部胶囊滑块随激活项平滑平移。
- R3.4 交互：点击任一胶囊段切换；触屏上在视图区横向滑动切换（左→下一个，右→上一个，到端停止）；键盘方向键支持。
- R3.5 位置：移动端位于终端内容下方、底部导航指示器上方；桌面端位于终端内容正下方，水平居中，与聊天输入框对齐；仅在「Sunam的电脑」顶级标签下显示（折叠态不显示）。
- R3.6 服务/终端面板在合并视图内保持挂载（用户 shell 进程不中断、服务面板瞬时态不丢），仅按胶囊激活态显隐。
- R3.7 容器启动时胶囊复位到 `ai`（展示启动中终端）；现有「容器关→仅能力库」「启动跳电脑页」行为不变。

## Acceptance Criteria

- [ ] 移动视口下两个终端均可单指纵向拖拽滚动；桌面滚轮滚动不回归；触摸监听无泄漏。
- [ ] 聊天气泡内超宽表格内部横向滚动，列不被挤压；窄表仍铺满气泡。
- [ ] 顶级标签与移动导航只显示 对话/电脑/文件/能力库（容器可用时）；终端/服务不再独立出现。
- [ ] 电脑视图内胶囊灵动岛 电脑→终端→服务 可点击切换、滑块平滑跟随、排序不变。
- [ ] 触屏横向滑动切换胶囊；无容器时电脑视图不渲染。
- [ ] 文件、能力库顶级标签行为不变；容器关→右侧栏仅能力库、移动导航仅 对话+能力库。
- [ ] 三语新增胶囊 aria-label 齐备。
- [ ] 组件测试更新/新增通过；`npm run check` 全绿（typecheck、lint、architecture、coverage、build、bundle）。
