# 子任务3：能力库 UI（右栏）（capability-library-ui）

> 父任务：`capability-library`。依赖子任务1（`capabilityRegistry`、`resolveEnabledTools`、`capabilityConfig`）与子任务2（`effectiveContainerState`、`retryContainer`）。本子任务交付能力库的可视化管理面板。

## 需求

### U1 右栏入口

- U1.1 **能力库作为右侧栏（虚拟容器栏目）的一个标签页**，与 终端/用户/文件/服务 同一栏目；移动端底部导航有同标签。
- U1.2 面板**不依赖容器可用性**：容器受限时该栏目照常渲染能力库（父任务 C6），纯聊天模式下右栏即能力库。

### U2 面板结构与双层开关

- U2.1 模块列表：一行一个模块，`图标 + 名称 + 描述 + 苹果风 switch（总开关）`。
- U2.2 容器模块总开关可**展开/折叠**，折叠区列出该模块全部工具，每个工具一行 `名称 + 描述 + 子 switch`。
- U2.3 其余模块（Agent运行时/资源附件）同样可展开管理子工具；笔记模块为**内置扩展占位**（`kind:'extension'`、禁用态，标注「即将以扩展模块随产品线合并上线」——试验田）。
- U2.4 总开关关 → 该模块所有子开关灰显且强制关；总开关开 → 子开关按配置生效。

### U3 档位与提示

- U3.1 Agent运行时模块与工具标注「不建议关闭」（黄标），关闭时二次确认（`capability.toggle.confirm`）。
- U3.2 容器模块展示态（**产品决策：正常态不显示文字徽标**——开关位置即状态）：
  - `已开启`：开关开启、可展开（无徽标）。
  - `已关闭`：开关关闭、可展开（无徽标）。
  - `启动受限`：异常态以备注 pill（黄）显示在标题下方「启动受限 · 点击重试」，**可点击重试**（触发 `retryContainer`），展开被禁用（受限时不可展开，父决策）。
  - 说明：`capability.status.enabled/disabled` 三语 key 保留备用，面板不渲染；此前曾短暂显示「已开启」徽标，按产品要求移除。
- U3.3 依赖工具：某工具开而其依赖关（如 `process_list` 依赖 `shell_run`）→ 自动补开并展示联动，或灰显提示「依赖未开启」，实现取一致语义。

### U4 持久化与联动

- U4.1 所有开关变更即时写 `CapabilityConfig`（`capabilityConfig.ts`），并触发注册表/运行时按新配置重建（经 `WorkspaceRuntimeProvider` 上下文）。
- U4.2 容器关 → 同步隐藏 Sunam 的电脑/终端/文件/服务（`Workspace` 不渲染 DualTerminal、Sidebar 隐藏容器区块、RunBoard 不显示恢复）。
- U4.3 **Agent run 活跃时容器开关禁用（禁止操作）**：run（含子 agent）活跃期间，容器模块总开关（含受限态点击重试）禁用——灰显 + tooltip「任务结束后可关闭」，避免 teardown 打断运行中任务；`interrupted`/`awaiting_user`/已结束 run 不锁定。开关改动沿用「下一轮任务生效」语义。
- U4.4 **关闭即释放由运行时承接**：面板只管触发开关偏好变更；flush 快照 → teardown → 释放内存的完整流程在 `WorkspaceRuntimeProvider`（子任务2 F4.4）执行，UI 不感知细节。

### U5 移动端

- U5.1 移动端（≤900px）面板以抽屉呈现，入口在移动导航。
- U5.2 与现有 `MobileNavigation`/`usePresence` 动效一致。

## 验收

- [ ] 右栏入口可开合面板；容器受限下面板仍渲染并显示「启动受限」。
- [ ] 核心四模块按序展示；容器模块展开/折叠工具列表；子开关逐项生效。
- [ ] 关容器总开关：容器工具全部强制关、灰显；UI 隐藏终端/文件/服务/侧栏容器区块。
- [ ] 受限态点容器开关：触发重试，成功恢复、失败回落不重复弹窗。
- [ ] Agent运行时「不建议关闭」黄标 + 关闭二次确认。
- [ ] 笔记扩展占位（禁用态、即将上线）展示。
- [ ] 开关变更持久化；刷新后状态保持；新工具按默认生效（override 语义）。
- [ ] Agent run 活跃时容器开关禁用（灰显 + 提示），run 结束后解除；关闭触发 flush 快照 → teardown（组件/单元测断言调用链）。
- [ ] 移动端抽屉可用；三语齐备。

## 不在范围

- 设置页重构、主题、笔记功能本体（后续任务）。
